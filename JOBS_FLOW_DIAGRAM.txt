╚═══════════════════════════════════════════════════════════════════════════════╝

1. USER ACTION
   └─ User types "React Developer" and clicks Search
        ↓
2. UI HANDLER (Jobs.jsx)
   └─ handleSearchJobs() called
        ↓
3. SERVICE CALL
   └─ searchJobs("React Developer")
        ↓
4. GOOGLE SEARCH (Serper API)
   └─ searchJobsWithSerper("React Developer")
   └─ Returns: { organic: [20 search results] }
        ↓
5. AI EXTRACTION (Groq API)
   └─ extractJobsWithGroq(searchResults)
   └─ AI extracts: [12 structured job objects]
        ↓
6. TRANSFORM DATA
   └─ transformJobsForDisplay(jobs)
   └─ Formats: [12 display-ready jobs]
        ↓
7. RETURN TO UI
   └─ { success: true, jobs: [...], total: 12, sources: [...] }
        ↓
8. UPDATE STATE (Jobs.jsx)
   └─ setJobs(result.jobs)
   └─ setJobStats({...})
        ↓
9. RENDER UI
   └─ Job cards displayed with "Apply Now" hyperlinks
        ↓
10. USER CLICKS "Apply Now"
    └─ Opens job posting on LinkedIn/Indeed/Glassdoor

╔═══════════════════════════════════════════════════════════════════════════════╗
║                         ERROR HANDLING FLOW                                   ║
╚═══════════════════════════════════════════════════════════════════════════════╝

Service Layer (jobSearchService.js):
├─ searchJobsWithSerper() fails
│   └─ Throws error → Caught by searchJobs()
│
├─ extractJobsWithGroq() fails
│   └─ Falls back to createFallbackJobs()
│   └─ Returns basic parsed jobs from search results
│
└─ searchJobs() fails
    └─ Throws error → Caught by UI handler

UI Layer (Jobs.jsx):
└─ handleSearchJobs() catch block
    └─ setError("Search failed. Please try again.")
    └─ Display error message to user
    └─ Console.error() for debugging
